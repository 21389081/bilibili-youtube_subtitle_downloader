# 插件視窗設計參考

參考：`popup-concept.png`。完整字幕選擇畫面；以 380px 寬 HTML/CSS 實作，不將概念圖作為介面。

- 純白底、深色文字 `#182c2a`、次要文字 `#717778`、青綠操作色 `#087c75`。
- 外側留白 24px；標題 24px，影片標題 16px，內文 14px，次要文字 12–13px。
- 元件：標題區、目前影片、分隔線、單選字幕列、主按鈕、重新搜尋按鈕、底部說明。
- 單選列 48px 以上，7px 圓角，選取時青綠外框；按鈕 44px 高度以上。
- 無圖片、徽章、卡片網格或裝飾性圖示；瀏覽器工具列圖示獨立於彈窗。
- 文字：字幕下載／YouTube · Bilibili／目前影片／選擇字幕／下載 TXT／重新搜尋／每段一行，不含時間碼／儲存位置沿用 Chrome 設定。
- 初始狀態為「開始下載」；搜尋、錯誤、無字幕及下載進度為必要功能狀態，與相同視覺元件共用樣式。
- 刻意差異：概念圖外側的灰色展示背景與陰影不屬於實際彈窗；影片名稱與字幕語言為動態資料。字幕清單超過高度後獨立捲動，避免超出 Chrome 彈窗限制。

比對重點：相同文案順序、標題層級、白底與青綠色、留白、單選列外框、主／次按鈕樣式及底部說明。檢查 380px 與 320px 寬度。

## 實作比對結果

實際 Chromium 截圖：`popup-implemented.png`。已使用 view_image 檢視概念圖與實作，並在 Browser/IAB 驗證初始按鈕、搜尋、語言切換與狀態更新。概念原圖 1116 × 1409 為展示板；實際彈窗固定為 380 × 560px。影片標題固定兩行，字幕清單在固定區域內捲動，狀態訊息預留高度；開啟、初始化、搜尋中與載入 30 個字幕時，搜尋按鈕及頁尾座標均維持不變。另以 32px 初始 viewport 重現 Chrome popup 啟動條件，確認 CSS 不會把指定的 380px 寬度壓縮成窄條。
