# 字幕下載 — YouTube 與 Bilibili

Chrome 擴充功能：取得目前影片的現成字幕，移除時間碼，以每段一行的 UTF-8 TXT 儲存。需求追蹤：[GitHub Issue #1](https://github.com/21389081/bilibili-youtube_str_downloader/issues/1)。

**狀態：可自行載入的第一版。** 18 項功能測試、瀏覽器完整下載測試及介面穩定性回歸測試通過；專案擁有者已在日常 Chrome 實測 YouTube 與 Bilibili 字幕下載成功。平台資料結構可能改變，仍需持續維護。

## 自行安裝第一版

1. 在 Chrome 網址列開啟 `chrome://extensions`。
2. 開啟右上角「開發人員模式」。
3. 點「載入未封裝項目」，選擇本專案的 **`extension` 資料夾**，不是專案根目錄。
4. 將「字幕下載 — YouTube 與 Bilibili」釘選至工具列。
5. 開啟影片頁面，左鍵點擊插件，再點「開始下載」。
6. 選擇字幕語言，點「下載 TXT」。檔案位置沿用 Chrome 的下載設定。

不需要 npm install、API key 或額外帳號。若使用 ZIP，先解壓縮，再選取包含 `manifest.json` 的資料夾。

## 行為

- YouTube：一般影片 `/watch`，以及具備現成字幕的 `/shorts`、`/live` 頁面。
- Bilibili：一般 `/video/BV…`、`/video/av…` 影片；只取得網址目前 `p` 對應的分 P。
- 搜尋僅在點擊「開始下載」後執行，不在背景掃描瀏覽紀錄。
- 包含平台提供的人工字幕與自動產生字幕；不做語音辨識、翻譯或繁簡轉換。
- 每個字幕段輸出一行，保留原順序與重複段落。同一字幕段內的換行轉成空格；純空白段略過。
- 不移除字幕內容本身提到的時間，例如「現在是 12:30」。不添加標題或影片連結至內文。
- 檔名為 `影片標題.字幕語言.txt`，多分 P 的標題包含 P 編號及分 P 名稱。非法檔名字元替換為底線，過長檔名截短。
- 同名檔案由 Chrome 加上流水號，不覆寫舊檔。省略 `saveAs`，沿用 Chrome 的「下載前詢問儲存位置」設定。
- 下載交給背景程序及 Chrome 處理；下載開始後關閉彈窗不會取消已交付的下載。重新開啟彈窗需重新搜尋。

## 已知限制與排錯

- 「此影片沒有可下載的字幕」只用於平台成功回傳無字幕的狀況。網路、登入、平台限制及格式錯誤另行顯示。
- Bilibili 部分字幕要求登入網站。插件沿用影片分頁的登入狀態，不讀取或儲存密碼。
- YouTube 字幕驗證方式可能變更。必要時插件會請播放器載入所選字幕，隨後恢復先前字幕選擇。若平台仍回傳空內容，先在播放器開啟所選語言字幕，再重新搜尋。
- 若影片尚在載入、播放廣告，或已切換影片／分 P，等待目前影片可正常播放後重新搜尋。
- 不支援嵌在影像中的硬字幕、批次播放清單、Bilibili 番劇 `/bangumi`、直播彈幕、互動影片分支或 Bilibili 國際版。
- 無法存取的影片、權限限制或平台風控不會被繞過。第一版不保證所有影片及字幕格式均可取得。
- 平台頁面及字幕介面可能改版，需要持續維護。商店上架尚未執行。

## 開發與驗證

需要 Node.js 20+，沒有執行階段第三方套件。

```powershell
npm.cmd test
npm.cmd run check
npm.cmd run package
```

Windows 打包產物：`dist/subtitle-text-downloader-0.1.0.zip`。安裝時直接選擇 `extension` 即可。

核心：`platforms/` 負責平台存取；`lib/text.js` 負責逐段文字轉換；`lib/video.js` 負責影片識別及安全檔名；`background.js` 驗證影片身分並處理下載。

人工驗收已使用有字幕的 YouTube 與 Bilibili 影片確認 TXT 下載。後續版本仍應驗證語言選擇、TXT 內容、多分 P、無字幕影片及切換影片後重試；並確認 Chrome「下載前詢問」開啟及關閉兩種設定均符合預期。

Chromium 自動測試使用暫存副本授予指定兩站的網站權限，以代替無頭模式無法執行的真實工具列點擊；交付版本維持 `activeTab`，並未加入永久網站權限。真實工具列點擊授權仍屬上述實機驗收項目。
